# JARVIS 1.3.3 — AI diagnostics

Installs over earlier versions (same application ID and signing key; data is kept).

* **TEST AI button** (Settings → AI CORE) – sends one tiny request to the selected provider and shows the result:
  `OK · provider · model · ms`, or the failure kind with the HTTP code and the server's reason. Use it to see at once
  whether a key, model name or free-tier limit is the problem.
* Includes 1.3.2 (Gemini model fallback on HTTP 404, error details) and 1.3.1 (Google TTS male voices, Male voices only).
